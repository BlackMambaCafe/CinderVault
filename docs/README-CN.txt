烬匣 CinderVault 1.0.5 · Windows 10/11 x64 便携版

开始使用
1. 解压整个文件夹；不要只拖出 EXE，也不要在 ZIP 中直接运行。
2. 双击 CinderVault.exe。所需下载组件已包含，不需要另装 Python、Node 或 FFmpeg。
3. 下载单个或多个视频：每行粘贴一个视频链接，选择保存位置、画质和同时下载数量，点击“添加并开始”。
4. 下载 YouTube 用户频道：展开“YouTube 频道批量下载”，粘贴用户主页，选择内容范围并点击“扫描频道”。扫描完成后，先勾选视频，再选择画质并点击“下载所选 N 个”。
首次运行默认画质为“最佳画质”，同时下载 2 个任务；修改后会记住设置，下次启动显示上次选择的实际值。
默认保存位置按当前电脑的“下载”目录生成，不含原作者的个人路径。
仅使用你有权保存的可访问内容，不读取浏览器登录凭据或绕过访问限制。

浏览和选择 YouTube 频道视频
支持 @用户名、/channel/频道ID、/user/旧用户名、/c/频道名的完整 HTTPS 链接，也接受普通视频、Shorts、直播回放分类页。
普通视频、Shorts、直播回放默认全部勾选，可在扫描前调整；进行中、预告中或尚未处理完成的直播会跳过。
扫描只获取列表，不下载视频。结果显示频道名称、已找到与跳过数量、视频标题和类型，每页最多显示 50 个视频。
扫描结果默认不选中任何视频。逐个勾选后，按钮会显示“下载所选 N 个”，旁边显示本次画质；未选视频时不能开始下载。
“本页全选”只选择当前显示的这一页；本页都选中后可点击“取消本页选择”。
“全选所有扫描结果”明确选择本次扫描的全部视频，包括其他页和当前搜索中未显示的视频；随后仍可逐项取消勾选。
“清空选择”取消全部选择。搜索或翻页会保留选择，不会把下载范围缩小为当前搜索结果。
搜索框可按标题或视频编号查找，点击“搜索”或按回车执行；清空搜索词再搜索可恢复完整列表。
重新扫描会清空选择。修改频道链接或内容范围后，必须重新扫描，避免下载旧频道列表中的视频。
扫描或加入队列期间会锁定相关操作；无法确认旧扫描进程已经停止时，需要退出并确认进程结束后再打开软件。

扫描中断与数量限制
正常完成后可选择结果；频道缺少某种分类时会提示，并继续扫描其他分类。
取消、超时或请求失败时保留已找到的列表，并明确标注结果可能不完整；可以选择已找到的内容下载，也可以重新扫描。
未完成的扫描重新开始时会从第一页枚举。扫描结果与下载任务会保存到下次启动；重新打开后需要重新勾选视频，不会自动下载。
所选视频按每批 100 条加入队列；队列每页显示 50 条，筛选和计数覆盖完整队列。
单次扫描和队列分别最多 100,000 条。达到上限会明确报错并保留结果，不会静默截掉后续内容。
需要登录、会员权限、下架或平台验证的内容不能保证下载；能列出标题不代表对应视频一定可下载。

画质、音频和保存位置
频道列表下方的“本次下载画质”和“频道保存位置”与上方单视频设置同步，点击下载时采用当前显示的值。
“最佳画质”不设置分辨率上限，优先可用的 MP4 视频和 M4A 音轨组合，必要时回退到其他可用格式；实际质量取决于站点提供的资源。
1080p、720p、480p 都是分辨率上限：源视频较低或相应格式不可用时，可能下载更低分辨率，不会把低清视频放大成高清。
“仅音频 · MP3”获取可用音轨并转为 MP3，不保存视频画面。音频转换使用最佳质量参数，不代表固定 320 kbps，也不会提升原始音源质量。
任务入队时记录自己的画质与保存位置；之后修改设置不会改变已经存在的任务。队列卡片会显示该任务请求的画质。
频道文件保存在所选目录中的 YouTube-频道ID 子目录。频道改名不会改变已识别的频道目录；暂时获取不到频道ID时，使用由频道链接生成的稳定目录名。
下载反馈会显示实际保存目录。单视频则直接保存在所选目录中。

文件名与旧任务续传
1.0.5 新任务的文件名格式为“YYYY-MM-DD 视频标题 [视频编号]-画质.扩展名”，例如“2026-10-01 示例视频 [abcdefghijk]-1080.mp4”。
日期使用平台提供的上传日期；没有上传日期时回退到发布日期，两者都没有时使用“日期未知”。这不是本次下载日期。
保留视频编号和画质后缀，用于区分同名视频及不同画质；不适合 Windows 的文件名字符会被处理，过长标题会截短。
旧版本保存的未完成任务继续使用原文件名，以复用原来的临时文件和断点。升级不会自动重命名已下载的文件。
续传需要保留原下载目录及临时文件，且平台仍提供可用资源；并非所有站点或下载格式都能保证从原断点继续。

重复下载与队列操作
只有成功生成并通过文件检查的下载才记入历史；清理已结束任务不会清除历史，也不会删除视频文件。
频道下载按“同一视频、同一画质、同一保存位置”检查重复：对应文件仍存在时跳过；文件已删除、换画质或换保存位置时，可重新加入下载。
相同画质和目录的任务已经在队列中时，不重复添加。所选的等待或暂停任务可以继续；失败和取消任务请使用队列中的“重试”。
“下载所选 N 个”只启动本次选择对应的任务，不会恢复其他已暂停任务。原本正在运行的队列会继续处理原有任务。
“继续队列”是全局操作，会继续整个队列中的暂停任务；需要只恢复部分频道视频时，请在扫描结果中勾选它们后下载。
支持 1—3 项并发、进度与速度显示、暂停、取消、重试和目录记忆。频道任务设有请求间隔，某条视频失败不会阻止其他任务。
退出后不会自动继续未完成任务；再次打开后手动选择或继续队列。完成后点击任务的文件夹图标可定位文件。
升级时如需保留队列和设置，应先完全退出软件、备份旧 data 目录，再把该目录复制到新版本旁；不要在两个版本之间同时使用同一份 data。
此分发包没有附带个人队列、下载历史、账号或缓存。data 文件夹首次运行时生成，请不要把自己用过的 data 文件夹转发给别人。

背景
默认只播放 backgrounds\background.mp4，静音循环。可以在设置中关闭动效。
替换时使用同一文件名，然后点击刷新；不提供古堡余烬或其他示例选项。

引擎更新
启动后后台检查 yt-dlp 官方稳定版，不会自动安装。成功检查缓存 12 小时；失败后 1 小时内不重复自动请求。
可随时在“引擎状态”点击“检查更新”。发现新版后，停止频道扫描、等待加入队列结束，暂停队列并等正在下载的任务完全停止，再点击“一键更新”。
更新期间禁止开始或重试下载，按钮会防止重复操作。检查更新本身不阻止正常下载。
新引擎通过官方 SHA256 及版本试运行后才原子替换；保留旧版备份，失败恢复旧版。异常退出后，下次启动会检查未完成事务。
若提示文件占用或无写权限，请关闭占用程序，或将完整文件夹放到当前用户可写的位置后重试；程序不会提权或改系统设置。
这里只更新 yt-dlp，不会自动更新烬匣本体、FFmpeg 或 Node。断网不影响使用已有引擎。
官方说明：https://github.com/yt-dlp/yt-dlp#update

支持范围
支持 YouTube 单视频及频道、B站视频与分P、Twitch 回放和片段；不录制进行中的直播。不支持任意播放列表入口。
站点可能因登录、地区、下架或网络限制失败，错误会显示在任务中。
程序未做自有代码签名；如果系统阻止运行，请先核实来源，不要关闭安全防护。
