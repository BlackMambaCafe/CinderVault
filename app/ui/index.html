    A LITTLE GUIDANCE

    三步，将光影收入匣中

    1. 01

      粘贴你的视频链接

      单视频可每行粘贴一个 YouTube、B站或 Twitch 官方链接。下载整个 YouTube 用户主页时，使用“频道批量下载”：选择普通视频、Shorts 或直播回放，扫描后浏览标题并勾选要下载的视频，再选择画质。默认不勾选；“本页全选”只选择当前页，“全选所有扫描结果”可选择整个列表。暂不支持播放列表和正在进行的直播。

    2. 02

      选好画质与保存位置

      默认获取可用的最佳画质；也可选分辨率上限或转换为 MP3。并发最高 3 个任务。

    3. 03

      开始下载，稍后重访

      在队列查看进度、暂停或取消任务。大队列可筛选和翻页；失败任务可单独重试。频道下载自动建立文件夹，清理队列后仍会记住相同画质与保存位置下的成功下载记录。扫描中断时，只能选择已找到的部分；搜索和翻页保留选择，重新扫描会清空选择。完成后点击文件夹图标，即可定位文件。

    仅处理有权下载的内容。需要登录、地域受限、付费或受 DRM 保护的内容可能无法下载。请遵守网站条款及适用法律。

    启动后会在后台检查 yt-dlp 官方稳定版，自动检查间隔至少 12 小时；也可在引擎面板手动检查。发现新版本后，先停止频道扫描、暂停队列并等待任务停止，再点击“一键更新”。更新前验证官方校验值及可运行版本，失败保留原引擎。此功能不会更新 FFmpeg、JavaScript 运行时或烬匣应用。

    引擎缺失时，请按照应用 README 安装 yt-dlp、FFmpeg 与受支持的 JavaScript 运行时，然后重新启动应用。
